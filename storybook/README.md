# Component Library

This contains all the needed components to build the user interfaces.

## Install

`npm install`

## Run Storybook for local development

`npm run storybook`

## Storybook library build for publishing as a package

`npm run build:lib`


## Building storybook (Static site visual )

This requires two steps ( build & Serve).

1. Create Static build 

`npm run build-storybook`

2. Serve the static build
 
`npx serve storybook-static -p 6006`
